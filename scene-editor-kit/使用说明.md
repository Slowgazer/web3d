# 场景编辑器 · 一键安装包

把整个 `scene-editor-kit` 文件夹发给别人，对方放进自己的 Three.js 项目里，**双击运行**即可自动配置；不想要了就**双击卸载**还原。

## 包里有什么

| 文件 | 作用 |
| --- | --- |
| `scene-editor.js` | 编辑器本体 |
| `scene-editor-autoload.js` | 自动挂载（一行 import 即生效） |
| `install-scene-editor.mjs` | 安装逻辑 |
| `安装场景编辑器.cmd` | Windows 双击安装 |
| `install.cmd` | 同上（英文名备用） |
| `install-scene-editor.command` | macOS 双击安装 |
| `uninstall-scene-editor.mjs` | 卸载 / 还原逻辑 |
| `卸载场景编辑器.cmd` | Windows 双击卸载 |
| `uninstall.cmd` | 同上（英文名备用） |
| `uninstall-scene-editor.command` | macOS 双击卸载 |

## 安装

1. 把整个 `scene-editor-kit` 文件夹拖进你的 Three.js 项目里（`package.json` 同级或更深的子目录都行）。
2. **双击** `安装场景编辑器.cmd`（Windows）或 `install-scene-editor.command`（macOS）。
   - macOS 若提示无法打开：右键 → 打开；或终端执行 `bash install-scene-editor.command`。
3. 脚本会：
   - 定位项目根（先向上找、再向下找 `package.json`）
   - 优先读 `index.html` 的 `<script type="module" src=...>` 作为入口
   - 把两个 `.js` 复制到入口同目录
   - 在入口顶部加 `import './scene-editor-autoload.js'`
   - 备份入口为 `<入口>.scene-editor-bak`，并写安装记录 `.scene-editor-install.json`
4. 启动项目（先 `cd` 到有 `package.json` 的目录，再 `npm run dev`），按 **Tab**。

## 预检：对方能不能用

安装器运行时会**先做预检并打印结果**，再决定是否安装：

- 项目根：找到 / 没找到（没找到 → 直接中止）
- 构建工具：检测到 `vite` / `webpack` / ... 或「未检测到」
- 入口文件：来自 html 的 `<script type="module">` / 扫描 `WebGLRenderer` 得到 / 没找到
- 是否使用 `new THREE.WebGLRenderer`
- 是否用 `<script src="...three.min.js">` 的老式全局写法

**判定「可能不适用」时会直接中止、不做任何修改**，并列出原因。

### 能用 / 不能用

**能用（满足其一即可）：**
- `package.json` 里检测到构建工具（Vite/webpack 等），**或**
- 入口来自 html 的 `<script type="module" src=...>` 且源码里用了 `new THREE.WebGLRenderer`

**不能用（典型）：**
- 纯 `<script src="three.min.js">` + 全局 `THREE` 的老式页面
- 非 Three.js 引擎（Babylon/PlayCanvas/自研）
- 找不到 `package.json`、也找不到带 `type="module"` 的 html

> 一句话：**用 Vite（或打包器）写 ES module、用 `THREE.WebGLRenderer` 渲染** → 能发。


## 安全说明（重要）

- 安装器**只新增文件、只在入口加一行 import**；**不删除任何文件、不改 `package.json`、不联网**。
- **不会覆盖**已有同名但不是本工具的文件（会跳过并提示）。
- 修改入口前**先备份**。
- 即使入口识别错了，最坏结果也只是「多了一行 import + 两个文件」，不会让项目损坏。

## 卸载 / 还原

双击 `卸载场景编辑器.cmd`（Windows）/ `uninstall-scene-editor.command`（macOS）：

- 依据 `.scene-editor-install.json` 精确移除入口里那段 import
- 删除由本工具复制且内容仍是原版的 `scene-editor*.js`
- 若你改过那些文件，则**保留**并提示，不会误删
- 没有安装记录时，按精确标记/签名**尽力清理**，只处理本工具的东西

> 还原可靠性：安装记录存在时基本可 100% 还原；记录丢失时按标记/签名尽力还原。两种方式都只动「能确认是本工具加的」内容，因此不会伤到其它文件。

## 操作速查

- `Tab` 进出编辑模式；单击选物体，`Ctrl/Shift` 多选
- `W/E/R` 移动/旋转/缩放，`Q` 世界/本地，`F` 聚焦，按住 `Ctrl` 吸附
- `Ctrl+Z` 撤销、`Ctrl+Y` 重做、`Ctrl+D` 复制、`Delete` 删除、`Ctrl+S` 保存
- 工具栏「导入」或拖拽文件：`.obj(+.mtl)/.gltf/.glb/.fbx`

## 高级用法

```js
// 显式传入，不用自动捕获
import { SceneEditor } from './scene-editor.js'
const editor = new SceneEditor({ scene, camera, renderer, controls })

// 配置（放在入口顶部）
window.__sceneEditorOptions = { unit: 'cm', storageKey: 'my-app:layout' }
```

- 默认自动捕获 `OrbitControls`；若用自定义相机控制，请显式传 `controls`。
- 依赖 Node.js（运行安装脚本）和 `three`（项目已有）。
